How to pack a live show by box number

Give each buyer in the show one box number, put that number on every item they win as it sells, and when the show ends you pack by box instead of reading through a sales list. Live Labels prints the box number on every label automatically.

The steps

  1. Before the show, set out boxes or bins you can number.
  2. As each item sells, label it with the buyer's box number. Live Labels assigns the number and prints it, along with the buyer, item and price.
  3. Drop the item in that numbered box. A buyer who wins three items gets three labels with the same box number.
  4. After the show, pack each box as one order and add the shipping label from your selling platform.
  5. Start the next show with box numbers counting from 1 again.

Why box numbers beat a sales list

A sales list makes you search for each buyer's items after the show. Box numbers sort items into orders while you sell, so combined orders are already together when you start packing.

Frequently asked questions

What is a box number?

Each buyer in a show gets their own box number, printed on every label for that buyer. When someone buys three items, all three labels say the same box, so you pack them together.

Does this work for giveaways?

Giveaways on Whatnot print a label like any sale. On Poshmark, giveaways are not read yet, so print those by hand.
