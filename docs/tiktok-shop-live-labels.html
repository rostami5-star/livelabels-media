Auto-print sale labels for TikTok Shop LIVE

Live Labels detects sales on TikTok Shop live show pages in Chrome and prints a label for each one with the lot number, the buyer's username, the item, the price, the buyer's box number and your shop logo, so every order is marked before your LIVE ends.

Then $10/month or $99/year, unlimited labels. No card needed to start.

How to set it up

  1. Add Live Labels to Chrome and run the setup wizard. It connects your thermal label printer and prints a test label in about two minutes.
  2. Open your TikTok Shop LIVE show page in Chrome on your computer.
  3. Open the Live Labels side panel and turn on Auto-print.
  4. Sell. Each sale prints a label you can stick straight on the item.

What prints on each label

  • Lot number
  • Buyer username and box number, the same box for every item one buyer gets
  • Item and price, as shown on the show page
  • Your logo

Printers that work

USB and Bluetooth thermal label printers print directly from Chrome, and any printer installed on your computer works through Chrome's print dialog. Built-in settings cover KNAON, JADENS, Nelko, Rongta, Phomemo, MUNBYN, POLONO, iDPRT, Rollo, Arkscan, Zebra, DYMO and Brother QL. Label sizes run from 2" × 1" up to 4" × 6".

Frequently asked questions

Does Live Labels work with TikTok Shop live?

Yes. It detects sales on TikTok Shop live show pages in Chrome the same way it does on Whatnot, and you can add other live-selling sites in its settings.

Does it replace TikTok Shop shipping labels?

No. It prints a sale label for each item during the LIVE so you can sort orders; shipping labels still come from TikTok Shop Seller Center.

Do I need a special printer?

No. USB and Bluetooth thermal label printers print directly from Chrome, and any installed printer works through Chrome's print dialog.
