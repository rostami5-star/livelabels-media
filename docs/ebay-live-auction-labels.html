Pick eBay Live in the Live Labels side panel, open your own show's page on ebay.com in Chrome, and each auction that ends prints a label with the winner, the item and the winning bid.

How to set it up

  1. Add Live Labels to Chrome and run the setup wizard. It connects your thermal label printer and prints a test label in about two minutes.
  2. In the Live Labels side panel, pick eBay Live and allow it to read ebay.com.
  3. Open your own show's page on ebay.com in Chrome and keep that tab open while you sell.
  4. Turn on Auto-print. Each auction that ends prints a label.

What it reads today

eBay Live auctions are read. Buy It Now sales on eBay Live are not read yet, so print those by hand from the side panel.

Printers that work

USB and Bluetooth thermal label printers print directly from Chrome, and any printer installed on your computer works through Chrome's print dialog. Built-in settings cover KNAON, JADENS, Nelko, Rongta, Phomemo, MUNBYN, POLONO, iDPRT, Rollo, Arkscan, Zebra, DYMO and Brother QL. Label sizes run from 2" × 1" up to 4" × 6".
