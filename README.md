# livelabels-media

Finished images and videos for Live Labels social posts. Metricool fetches them
from here when it publishes to Instagram, Facebook and TikTok, so this repo is
public. Marketing assets only: no code, no private data.

The source files (and the scripts that render them) live in the private
`btc-arb` repo under `live-label-printer/marketing/`.

| Folder | What |
|---|---|
| `box-numbers/` | Box-number ads (post 1080×1350, story 1080×1920) |
| `batch-2/` | Box-numbers reel, meme, seller tip, printer poll, before/after |
